# 12 · Business, Mediation + Documentation Plan

> Figma Node: `40:1674` · Planning Pack · 14 Sep 2026

Commercial and mediation workflows support defensible decisions; they never sell certainty, scientific outcomes or regulatory success.

## Dossier Anatomy

1. Executive memo, issue tree, workplan
2. Evidence library, assumptions, interviews
3. Commercial/financial models and scenarios
4. Risk register, recommendation + dissent
5. Roadmap, decision log, appendices
6. Version, owner, reviewer and approvals

## Gate Lifecycle

1. Intake → sufficiency → scope → analysis
2. Independent challenge → decision review
3. Approved / Conditional / Paused / Stopped
4. Versioned follow-up
5. Each gate: artifacts, criteria, owner, reviewer, date, exceptions, override rationale, next decision
6. rNPV/TAM/PoS expose sources, cohorts, dates, currency, overrides, limits

## Delivery + Verification

1. In-house: workflow, evidence controls, models, dossier
2. Partner-delivered: specialist work under SOW
3. University/agency/CDMO: source → checker → date → expiry → scope → limitations
4. Badge meaning is narrow and auditable
5. SOW + change order govern scope
6. Marketplace ranking discloses sponsorship/referral

## Mediation + Price Truth

1. Authority, COI and confidentiality checks
2. Neutral selection; controlled evidence exchange
3. Issues, positions, options, binding status
4. Approvals and unresolved matters
5. User-supplied price ranges: PENDING VALIDATION
6. Disclose scope, method, exclusions, referral and legal/regulatory limits
