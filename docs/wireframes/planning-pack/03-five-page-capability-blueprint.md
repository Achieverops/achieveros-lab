# 03 · Five-Page Capability Blueprint

> Figma Node: `40:1310` · Planning Pack · 14 Sep 2026

Each page has a singular job and explicit boundaries. Secondary capabilities arrive only when summoned by the work.

## Command + Ideation

- **COMMAND job**: resume, triage exceptions
- Surface: queue + selected-project preview
- Creates: task, project action; consumes runs/decisions
- Assistant summarizes exception with citations
- Not here: admin grid, analysis studio
- **IDEATION job**: shape testable hypotheses
- Surface: full evidence canvas; source tray + closed inspector
- Creates Question/Claim/Gap/Hypothesis/Test
- 10-step envelope expands over center only

## Visualization

- Job: inspect, compare, explain analysis
- Surface: full-space viewer; collapsed nav/inspector
- Modes: chart, table, spatial, network, notebook output
- Data: snapshots, BigQuery/lake assets, WASM metadata
- Versioned filters + provenance strip
- Compare is explicit split-screen
- Tools/partners open retractable overlay
- Not here: literature screening or marketplace browse

## Literature

- Job: produce reproducible evidence synthesis
- Search → Dedupe → Screen → Full text → Extract → Assess → Synthesize
- LlamaParse/LlamaIndex, Fabric, Arrow IPC, Scite
- Dual review + controlled exclusion reasons
- Extraction links exact passage
- PRISMA from workflow events
- Assistant proposes; reviewer promotes
- Not here: freeform canvas or tiny reader

## Business & Mediation

- Job: govern consequential decisions
- Surface: decision dossier + gate rail
- SCQA/MECE, assumptions, rNPV/TAM/PoS, risk, dissent
- Partner/university/CDMO launcher; mediation issues
- Approvals and immutable decision log
- Exports: board memo, SOW, evidence pack
- Prices disclose scope/method; outcomes never implied
- States everywhere: Ready/Degraded/Blocked/Failed/Stale
