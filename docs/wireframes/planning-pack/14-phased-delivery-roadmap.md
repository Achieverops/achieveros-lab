# 14 · Phased Delivery Roadmap

> Figma Node: `40:1742` · Planning Pack · 14 Sep 2026

Planning precedes wireframe edits; approved wireframes precede contracts; verified contracts precede integration and deployment.

## Stage 0–1 · Establish Truth

1. Verify repo paths, commits, tests, deployments and lane claims
2. Inventory current objects, adapters, APIs and failure evidence
3. **GATE A**: evidence baseline approved
4. Build shared shell, canonical object model, status semantics, deep links
5. Define server/Zustand boundary and provenance contract
6. **GATE B**: architecture + security approval

## Stage 2–3 · Specify Experience

1. Review five page populations and all state wireframes
2. Validate 8 presets and contextual surface thresholds
3. **GATE C**: explicit approval before changing product frames
4. Produce implementation contracts, schemas, events and accessibility criteria
5. Then generate Cursor build instructions
6. **GATE D**: contract/test-plan sign-off

## Stage 4–5 · Integrate + Prove

1. Connect L0–L6, LlamaIndex, governed data and compute
2. Add resource router, notebook and bounded agents
3. E2E, security, performance, tenancy and cost tests
4. Clinical/regulatory review for relevant workflows
5. Failure injection, stale deploy and degraded-mode drills
6. **GATE E**: release-readiness approval

## Stage 6 · Deploy + Observe

1. Approved deployment with immutable release evidence
2. Progressive exposure and rollback thresholds
3. Observe latency, spend, retrieval, failures and user outcomes
4. Audit state truth and partner disclosures
5. Capture follow-up decisions as versioned objects
6. **GATE F**: expand, pause or rollback
