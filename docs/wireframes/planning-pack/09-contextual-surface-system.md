# 09 · Contextual Surface System

> Figma Node: `40:1572` · Planning Pack · 14 Sep 2026

Protect the dominant canvas. Add capability by progressive disclosure, never by permanent longitudinal columns.

## Trigger Rules

1. **Button**: atomic action or compact launcher
2. **Bar**: persistent status/provenance with no reading burden
3. **Drawer**: inspect one selected object; one open by default max
4. **Tray**: browse sources/files without replacing canvas
5. **Overlay**: substantial tool while retaining dimmed context
6. **Full screen**: high-density viewing, authoring or comparison

## Named Surfaces

1. INNOVATION dock → envelope over center only
2. Filing library → retractable drawer
3. Assistant → selection-bound inspector
4. Software/tool → large overlay or full viewer
5. Notebook → resizable panel with immutable inputs
6. Source tray → bottom/side tray
7. Compare → explicit reversible split mode

## Continuity Rules

1. Opening a tool preserves zoom, selection and filters
2. Overlay leaves readable context edge and return path
3. Only one modal-depth surface at a time
4. Esc/back closes one layer without data loss
5. Full-space tools never squeezed into vault
6. No white canvas modal over Snow context

## Failure Guardrails

1. No four permanent middle columns
2. No Bolt fragmentation for full-page experiences
3. No tooltips or vaults hijacking focus
4. No ledgers/LLM grids promoted to pages
5. No half-page white void or narrow workbench
6. Empty canvas always offers resume, sample or import
